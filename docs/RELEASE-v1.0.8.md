# Markdown 阅读编辑器 v1.0.8

本次修复重复打开同一 Markdown 文档时创建多个窗口的问题。

## 本次更新

- 重复打开同一 `.md` 或 `.markdown` 文件时，恢复并激活已有窗口，不再创建副本。
- 保留原窗口中的未保存内容与阅读位置，不重新加载文件。
- 资源管理器与文档内 Markdown 链接使用同一套窗口识别规则。
- 启动阶段和快速连续打开同一文件时，也只创建一个窗口。
- Windows 下支持路径大小写、斜杠及相对路径差异；关闭文件后可再次打开。
- 不同文档仍可分窗对比，保持独立保存和关闭提示。

## 下载

- `Markdown-Editor-Setup-1.0.8.exe`：Windows x64 安装版。
- `Markdown-Editor-1.0.8.exe`：Windows x64 免安装版。
- `markdown-reader-source-1.0.8.zip`：独立源码包。
- `SHA256SUMS.txt`：以上附件的 SHA-256 校验值。

安装包内源码已与测试代码核对，源码及打包后的多窗口回归测试均已通过；已验证未保存内容保护、路径别名、启动并发、独立保存、关闭后重新打开及 Markdown 导出。

普通 Markdown 阅读与编辑不需要 Node.js、Python 或 AI 账号。可选文档转换的依赖安装方法见仓库 README。
