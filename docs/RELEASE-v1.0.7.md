# Markdown 阅读编辑器 v1.0.7

AI 生成了越来越多的 Markdown 文档。我们不一定每次都要打开 AI 工具，有时只是想打开一份本地文档，清楚地看一看内容。

Markdown 阅读编辑器提供实时预览、多窗口阅读、Mermaid 图表、目录导航、常用编辑和多格式导出，让 `.md` 文档更方便阅读、整理和分享。

## 本次更新

- **从资源管理器打开其他 Markdown 文件时，新建窗口。** 原窗口及未保存的修改会保留，方便两份文档并排对比。
- 连续打开多个文件时，每个文件拥有独立窗口。
- 关闭首个窗口后，仍可继续打开其他文档。
- 保留 Ctrl＋单击 Markdown 链接的新窗口打开方式。
- 已验证多窗口独立保存、未保存提示和基础导出功能。

## 下载

- `Markdown-Editor-Setup-1.0.7.exe`：Windows x64 安装版。
- `Markdown-Editor-1.0.7.exe`：Windows x64 免安装版。
- `markdown-reader-source-1.0.7.zip`：独立源码包，含中文说明与构建方法。
- `SHA256SUMS.txt`：以上附件的 SHA-256 校验值。

普通 Markdown 阅读无需安装 Node.js、Python，也无需登录 AI 服务。导入一般 DOCX / HTML / PDF 的转换功能需要另行安装 Python 和 MarkItDown，详情见 README。

此次开源整理使用现有的 1.0.7 二进制发行包，发布文件仅使用英文文件名便于下载，文件内容未改变。
